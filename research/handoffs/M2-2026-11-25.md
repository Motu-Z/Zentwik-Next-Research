# M2 交接（2026-11-25）

## 已完成

- **应用层拆分**：新增 `Zentwik.Core`（`net10.0-windows`），承接方案协调、场景引擎、账本、状态存储、能力聚合、模块目录、诊断。`Agent` 只保留 IPC 会话、服务宿主与装配。
- **CLI 转为正式入口**：新增 `CommandLine`/`Output`/`Help`/`Commands`，覆盖状态、能力、模块、监控、调校、方案、场景、账本、设置、诊断、日志；支持 `--json`、统一退出码。
- **服务化骨架**：`--service` 走 `StartServiceCtrlDispatcherW`；`--install-service`/`--uninstall-service` 走 SCM；管道改显式 DACL，建连前校验调用方 SID、完整性级别与 Session。
- **AMD CO 读写通道**：`PawnIoSession` + `AmdSmuTuningProvider`，按 Family/Model 选命令族，就绪探测，逐核 Get / Set 后回读校验，失败缓存 10 秒。
- **硬件能力与失败表达**：`HardwareAvailability`（Available/NotSupported/DriverUnavailable/ModuleMissing/ProbeFailed）映射到能力状态；Intel MSR 明确报"尚未实现"。
- **方案应用语义**：写前记前值 → 写入 → 回读 → 不符即失败；账本区分 `Owner`（Scene/Plan/User/System），手动 apply 不被场景回退。
- **场景真正接入账本**：2 秒触发评估、优先级仲裁、切换时回退旧场景、`scene.changed` 事件、方案版本不符跳过。
- 构建 0 警告 0 错误；测试 49 个（Domain 25 / Core 6 / Contracts 18）全部通过。
