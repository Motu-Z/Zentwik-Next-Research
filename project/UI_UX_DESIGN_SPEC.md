## 1. 设计原则与核心心智

1. **Live-First（先调后存）**：所有硬件调校、进程调度与电源策略优先支持即时编辑与试探；是否固化为持久方案（`Plan`）由用户通过顶栏 `保存并应用 / 新建并应用` 主动决定。
2. **三域独立 `PlanHub`**：严格隔离 `CpuTuningPlan`、`SchedulingPlan`、`PowerPlan` 三类方案，不设跨页“全量保存”。`Scene` 仅作为跨页协调器，不直接持有硬件参数。
3. **Capability-Driven（能力驱动，默认隐藏）**：
   - 未安装的可选组件、未启用功能或当前硬件不支持的寄存器/特性**默认隐藏**，且不启动后台轮询与采集。
   - 仅当用户在 **系统设置 → 外观与语言** 开启「显示未启用或不可用模块」时，才以虚线/只读占位呈现。
4. **去千禧年控制台化（单平面、去边框、无原生控件）**：
   - 禁止多层嵌套矩形框与横穿全屏的表格网格线；用字体对比度、留白、微弱交替行底与悬停显形建立秩序。
   - 全局禁用原生 `<ComboBox>` 视觉样式与传统复选框堆砌，统一使用自定义毛玻璃弹出选择器与拨动开关。

## 2. 全局壳层与导航骨架（C1 领域工作台）

- **极简标题栏（36px）**：
  - 左侧：仅保留产品标识与 Worker 连接状态；不在标题栏重复展示 CPU 型号、核心/线程数或 AC/DC 电源状态，硬件信息由系统脉搏及对应监控组件承载。
  - 右侧：严格精简为 **5 个图标**——`场景快控`、`运行记录`（状态核对与近期事件统一入口，含需关注角标）、以及系统窗口三键（最小化 / 最大化 / 关闭）。外观设置回归「系统设置」，不占标题栏。
- **可折叠左侧导航栏**：
  - **直接点击左上角 Zentwik Logo** 展开或收起导航栏（不设额外折叠按钮）。
  - 导航项：主区 `首页总览`、`CPU 调校`、`电源管理`、`进程与调度`、`场景自动化`、`方案库`；底部 `能力与诊断`、`系统设置`。
- **视觉变量**：
  - 主题：`深色` / `浅色` / `跟随系统`。
  - 信息密度：三档可调（`宽松` / `标准` / `紧凑`）。
  - 强调色：预设色板 + 自定义拾色器（带对比度安全钳位），实时联动 Logo 光晕、选中指示条与主按钮。

## 3. 核心页面规格

### 3.1 首页总览（可扩展模块化架构）
- **定位**：实时监控、状态总览与快速直达入口，不承载写入保存动作。
- **结构**：
  - **顶部脉搏带**：只承载封装功耗、核心温度、有效频率等硬件遥测；当前活动场景由独立的「当前场景」组件呈现，不在脉搏带重复显示。
  - **功能域与扩展槽位（自适应 Bento 网格）**：首页采用 12 列自适应组件网格。默认挂载系统脉搏、功能域、当前场景、运行记录等组件；未来 GPU 调校、历史监控与告警、插件扩展按同一组件接口接入。
  - **运行记录（统一状态与事件流）**：合并原 StateLedger 首页状态账本与近期动态。状态核对、用户接管、场景命中和运行事件进入同一时间序列；每条记录保留时间、对象、说明、状态与来源域，并提供「全部 / 需关注 / 状态核对 / 运行事件」筛选。状态核对项展示最近一次回读状态，事件项保留发生时间，二者在同一流中区分呈现。
  - **组件个性化**：提供组件库和「自定义组件」入口。用户可添加、隐藏、恢复，并通过拖动组件手柄调整顺序；组件右边缘调整宽度、下边缘调整高度、右下角同时调整宽高。宽度按网格列数吸附，高度按 40px 步长并受内容最小高度约束；尺寸、顺序和组件配置持久化。组件工具区提供「从首页移除」，默认组件和组件库组件可重新添加，自定义组件定义可单独永久删除并二次确认。用户还可创建自定义指标卡或信息便笺。未安装、硬件不支持或能力未启用的组件默认不列入可添加清单。
  - **组件扩展契约**：功能模块通过组件描述注册到首页，至少声明稳定 ID、标题、所需能力、数据源绑定、配置 schema 和建议尺寸。UI 不直接执行任意第三方脚本；扩展由已安装且获准的模块提供。

### 3.2 CPU 调校
- **能力驱动显隐**：仅渲染当前平台（AMD SMU / Intel MSR）实际支持的模块。
- **互斥模式设计**：
  - `Curve Optimizer (CO)` 与 `Curve Shaper (CS)` 互斥切换；
  - `All-Core` / `Per-CCD (Cluster)` / `Per-Core` 互斥切换；
  - `FMax` 与 `Manual OC` 互斥切换（OC 同样支持全核 / 分簇 / 分核）。
- **核心交互**：EQ 柱状偏移条调节 CO；12/24+ 核心处理器采用按 CCD / P·E 簇折叠的手风琴结构；完整呈现平台功耗/电流/温度墙（`STAPM / PPT / TDC / EDC / TjMax` 及 Intel `PL1 / PL2 / Tau / ICCMax`）。

### 3.3 进程与调度 & 核心掩码库
- **主进程流（去框平权）**：
  - 列结构：`进程与路径`（主行为进程名 + 紧贴右侧的 5px 纯状态点；副行为等宽路径） | `PID` | `CPU`（纯等宽数字，无进度条） | `调度目标` | `优先级`。
  - **大界面不显示 `AM / CS` 后缀**，仅显示目标名称；未调度与已调度行保持字重平权，单元格常态无边框无底色，悬停显形可点击编辑。
  - 完整桌面交互：表头排序、`Ctrl / Shift` 多选（底部悬浮批量操作岛）、右键菜单（含 `打开进程所在目录`、`复制路径`、`存为持久规则`、`释放用户接管`、`解绑恢复默认`）。
- **顶栏方案闭环**：`PlanHub` 方案胶囊支持切换、重命名、删除、另存为及未保存切换防丢确认；右键「存为持久规则」写入当前规则集并同步触发方案脏状态。
- **右侧悬浮毛玻璃「策略坞」**：
  - **已保存规则**：保留右置纯状态点；处于「用户接管」的琥珀黄点支持**直接点击原位弹窗确认释放**；点击规则卡片可高亮/过滤左侧命中进程。
  - **核心掩码库（严格两层下钻）**：
    - **第一层（列表）**：卡片展示名称、`CORE` 等宽范围与右上角同色中性 `CS / AM` 微标。
    - **第二层（硅片拓扑刷选编辑器）**：包含名称、`CPU Sets (CS)` / `Affinity Mask (AM)` 绑定方式切换（多处理器组自动禁用 AM）、快捷预设、**按 CCD / P·E 异构簇排布且支持鼠标按住横扫拖拽刷选（Brush Select）** 的物理核与逻辑线程（`T0 / T1`）画布，底部双向联动十六进制掩码。

### 3.4 电源管理
- **顶栏**：同时绑定 `Zentwik 电源方案` 与 `Windows 系统电源计划`（支持切换、复制新建）+ `回读` / `保存并应用`。
- **AC / DC 双列矩阵**：按功能域分组展示 8 项核心策略，常态平铺、悬停显形；数值型策略（如最小/最大处理器状态、核心停泊比例）支持弹出层内**快捷档位 + 任意整数精确输入**；BIOS/系统不可写子项在行尾以轻量状态提示跳过原因（如 Win32 错误码）。

### 3.5 场景自动化（vNext 规则引擎）
- **结构拆层**：`WHEN（触发源）` + `IF（附加前提，如仅限 AC/DC）` → `THEN（调校 / 调度 / 电源三域独立动作）` → `ON EXIT（退出自动恢复）`。
- **多目标条件集合**：进程类触发支持**多进程名标签池**（支持从运行中进程快速勾选）及**目录路径前缀匹配**，避免为同类应用重复建规则。
- **优先级与按域独立仲裁**：
  - 规则左侧显式展示 `#1 / #2 / #3...` 优先级序号，支持**直接拖拽 `#n` 上下排序**及 `▲ / ▼` 微调。
  - 默认采用**按域独立 · 高优先级胜出**仲裁：多条命中规则可跨未冲突域自动组合，仅在同一域内由高优先级胜出（低优先级被压过项在视图中以删除线直观标示）。

### 3.6 方案库
- **单列行内展开**：按 `调校方案 / 调度方案 / 电源方案` 分段查看，不设右侧栏与多余新建入口；点击方案行直接在下方展开**已保存快照 vs 当前实时状态**的逐项差异（Diff），有未保存改动时就地提供 `放弃改动` 与 `覆盖保存`。

### 3.7 能力与诊断（含运行日志）
- **双子页签**：`能力探针` | `运行日志`（区分 `UI / Worker` 来源与分级过滤，收口原 `LogsView` 能力）。
- **对齐安装与部署架构**：顶部展示实例部署模式（`标准安装 Registered` / `便携部署 Portable`）、`UI + Worker` 双进程状态及程序/数据分离目录，并提供 `Zentwik Maintenance` 入口。
- **组件与探针隔离**：区分「安装状态（已安装 / 未安装可选组件）」与「运行状态（运行中 / 已启用 / 未启用 / 部分受限）」，未安装组件不报红灯故障，仅提供按需跳转 Maintenance 安装入口。

### 3.8 系统设置（子选单分区）
左侧轻量级子选单分四区承载，支持后续无压力扩展：
- **外观与语言**：主题、三档密度、强调色、**显示未启用或不可用模块开关**、界面缩放、语言。
- **运行与行为**：开机启动（Windows 计划任务）、关闭主窗口行为、后台内存修剪。
- **保护与集成**：启动异常自动拦截（BootGuard）、休眠唤醒恢复、桌面右键菜单。
- **部署与数据**：`Zentwik Maintenance` 入口（组件变更 / 修复 / 部署模式转换）、配置备份导出、重置全部数据。
