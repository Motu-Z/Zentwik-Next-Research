# Zentwik Home Rebuild v2 · Translucent Workspace

## 验证目标
验证以 NectarLink Glass 截图为参考的半透明桌面材质，能否在 Zentwik 首页保持专业数据工具所需的可读性与信息密度。

## 设计处理
- 保留已确认的 C1 领域工作台信息架构、左侧可折叠导航、四项系统脉搏、功能域、StateLedger、当前场景与近期动态。
- 以半透明层、背景柔光、弱边界和材质叠层取代 V1 的不透明矩形卡片与明显边框。
- 保留深浅主题、三档信息密度和用户自定义强调色；不锁定强调色。
- 使用非对称主次列，主列承载功能域和状态账本，辅助列承载场景和动态。
- 所有遥测均为模拟数据，不连接真实硬件。

## 运行
直接使用现代浏览器打开 `zentwik-home-rebuild-v2.html`。

## 交互
- 顶部原型栏：深浅主题、紧凑/标准/宽松密度、强调色。
- 点击左上角 Zentwik 标志折叠/展开导航。
- 顶栏场景与 StateLedger 图标打开浮层。

## 成功标准
1. 玻璃材质用于分层而非全屏无差别模糊。
2. 数值、状态和异常在深浅主题下均保持清晰。
3. 强调色只承担交互与状态焦点，不取代语义状态色。
4. 不增加多层嵌套卡片，不改变已确认的产品信息架构。

## 已知限制
这是独立 HTML 视觉原型，不是 WPF 实现；`backdrop-filter` 在目标 Windows/WPF 中需要以实际渲染能力重新实现或降级。当前数据为静态演示数据。
