# Zentwik Home Rebuild v3.2 · Modular Glass Workspace

## 本轮调整

### 1. 合并状态账本与近期动态
- 首页不再并列显示「状态账本」和「近期动态」。
- 统一为「运行记录」：将状态核对、用户接管、场景命中和运行事件放入同一时间序列。
- 单条记录同时保留时间、对象、事件说明、当前状态和来源域。
- 支持「全部 / 需关注 / 状态核对 / 运行事件」筛选。
- 标题栏原状态账本图标改为跳转到运行记录，不再开启重复的账本浮层。

### 2. 收敛其他重复信息
- 顶部「系统脉搏」只放硬件遥测：封装功耗、核心温度、有效频率；活动场景不再重复出现。
- 当前场景只在「当前场景」组件中展示具体名称、触发进程、覆盖域、优先级和退出行为。
- 「场景自动化」功能域卡片改为显示规则总数和命中数，不再重复显示当前场景名称。
- 场景卡不再复述 CPU / 电源等功能域卡片中的方案状态。

### 3. 组件化首页
- 首页使用 12 列自适应组件网格，组件可使用 4 / 6 / 8 / 12 列宽度。
- 「添加组件」打开组件库，可添加 GPU 状态、内存占用、CPU 核心负载、温度趋势、进程焦点和快捷操作。
- 「自定义组件」支持用户创建单值指标或信息便笺，可选择已有指标数据源或录入自定义数值。
- 「编辑布局」改为直接拖动组件手柄调整顺序，不再提供上移 / 下移按键；拖动组件右下角的尺寸手柄调整宽度（桌面端 4 / 6 / 8 / 12 列，平板端按 6 列网格适配）。
- 每个组件提供 `×`，可从首页移除；默认组件和组件库组件均可重新添加，自定义组件可在组件库管理区恢复。自定义组件的「删除定义」需要确认，才会永久删除，与从首页移除分开。
- 组件宽度、顺序和移除状态写入布局配置，重新打开原型后保留。
- 首页布局和用户组件配置在浏览器允许的情况下写入 localStorage。

## 本次交互修订（v3.1）

- 移除首页组件的方向按键，改为拖动排序。
- 增加右下角拖动尺寸手柄，拖动时按网格列数吸附，并保存尺寸。
- 为默认首页组件增加「已从首页移除」恢复区，避免移除后无法找回。
- 明确「从首页移除」与「删除自定义组件定义」的区别。

## 原型验证边界

- HTML / CSS / JavaScript 独立原型，不是 WPF 正式实现。
- 组件库的遥测值均为演示数据；自定义数据源目前使用示例映射，不是真实 Worker 数据绑定。
- 组件扩展机制目前完成的是首页容器、组件注册入口和交互模型。正式产品需要由各模块通过组件描述、能力要求、数据绑定和配置 schema 注册，不应允许任意脚本直接插入 UI 进程。
- 玻璃材质中的 `backdrop-filter` 仍需在 WPF 目标渲染栈中评估和降级。

## 本次交互修订（v3.2）

- 标题栏移除 CPU 型号、核心/线程数和 AC/DC 信息，只保留品牌与 Worker 连接状态。
- 组件尺寸改为二维拖动：右边缘调整宽度，下边缘调整高度，右下角同时调整宽度和高度。
- 宽度继续按网格列数吸附；高度以 40px 为步长，并受组件内容最小高度和 1200px 上限约束。
- 宽度和高度分别持久化，拖动组件排序不会清除已经保存的高度。
- 组件尺寸手柄在手机窄屏隐藏，避免单列布局中出现无意义的尺寸控制。
