# Zentwik Home Rebuild v3.3 · Content-aware Modular Workspace

## 本轮改动

### 1. 组件内部内容管理
- 每个首页组件在「编辑布局」模式中提供「内容」入口。
- 原有内容项可逐项关闭或恢复，不需要删除整个组件。
- 用户可向当前组件追加自定义内容：名称、可选数值、单位和补充说明。
- 自定义内容可以单独删除；内容设置随首页布局保存在本机。
- 已覆盖系统脉搏、功能域、当前场景、运行记录，以及 GPU、内存、CPU 核心负载、温度趋势、进程焦点和快捷操作等组件。

### 2. 内容驱动的自动高度
- 默认组件高度由实际内容决定，不再预留固定空白高度。
- 增加内容、恢复内容时自动增高；隐藏或删除内容时自动收缩。
- 手动拖动高度后进入手动高度模式；当内容增长超过当前高度时，组件会扩展以避免裁切。
- 组件工具区的「自动高度」可以清除手动高度，恢复内容驱动的自动伸缩。
- 宽度仍按首页网格列数吸附；二维尺寸拖动和拖动排序继续保留。

### 3. 页面结构
- 保留状态账本与近期动态合并后的「运行记录」组件。
- 保留用户自定义强调色、深浅主题、信息密度和窄屏布局。
- 未安装或不支持的组件仍遵循能力驱动隐藏规则。

## 交互测试
- 对默认四个组件及六个组件库组件逐一打开内容管理，原有内容项均能被识别。
- 原有内容项隐藏/恢复、自定义内容添加/删除、内容增加后高度增长、删除后高度收缩均通过。
- 手动高度与「自动高度」模式切换通过。
- 390px 窄屏无横向溢出，JavaScript 页面错误为 0。

## 限制
- HTML / CSS / JavaScript 独立交互原型，不是 WPF 正式实现。
- 遥测内容仍为演示数据；当前自定义内容是用户维护的本机显示条目，不是新的 Worker 数据源。
- 正式产品需要把内容编辑 schema 与组件注册契约连接起来，并将自动尺寸逻辑映射到 WPF 布局。
